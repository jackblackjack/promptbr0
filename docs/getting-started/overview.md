# PromptBr0 overview

PromptBr0 is a local-first prompt library for creating, organizing,
testing, and improving AI prompts. Your library stays on your computer. The
desktop app and CLI use the same library, so you can work in the
interface you prefer without copying prompts between tools.

## What you can do

- Create prompts, amend a version or save a new one, and try variations without
  losing a known-good version.
- Find prompts with search, tags, collections, stars, notes, and filters.
- While PromptBr0 is running, find, preview, and copy a saved prompt from
  another app with the optional Quick access palette.
- Keep working with prompts after closing the library window: the optional
  system-tray mode offers **Show** and **Quit** without restarting the app.
- Run a prompt with one or more connected AI models, compare results, and
  record ratings and costs.
- Let coding agents read prompts, report their results, and propose changes
  for you to approve in the desktop app.
- Use a website's **Open in PromptBr0** link for a public HTTPS Markdown
  file, review it in the desktop app, and import it as a new local prompt.
- Keep your library in sync between your own desktop devices on a local
  network or VPN.

## What stays local

Browsing, editing, versioning, and search work without an account or internet
connection. Model runs, model catalog refreshes, and
fetching a public Markdown file need a network connection. API keys remain on
the device where you add them.
